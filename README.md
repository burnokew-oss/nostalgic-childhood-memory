## Entry

> On rainy August afternoons at my grandmother's house in Bandung, I would run in from the dusty yard just as the rain hit the tin roof, press my bare feet to the cool cement floor, and breathe in the smell of fried tempeh from her kitchen, wishing the holidays would never end.

276 characters, one sentence.

## Run

`main.py` (pure Python standard library, no dependencies) writes the entry to `/output/entry.txt` with no trailing newline:

```sh
python3 main.py
```
